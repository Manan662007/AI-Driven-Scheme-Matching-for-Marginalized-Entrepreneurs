# 🤖 Scheme Saathi

### AI-Driven Scheme Matching for Marginalized Entrepreneurs

**Scheme Saathi** is an AI-powered platform that helps entrepreneurs, students, MSMEs, and other users discover **relevant government schemes and support programs** based on their personal and business requirements.

Instead of searching through numerous schemes manually, users can describe their needs in natural language and receive **context-aware scheme recommendations** with relevant information.

## 🚀 Key Features

* 🔍 **AI-Based Scheme Matching** — Matches user requirements with relevant government schemes.
* 💬 **Natural Language Interaction** — Users can describe their needs in natural language.
* 🎯 **Personalized Recommendations** — Considers user context and eligibility-related information.
* 📚 **Scheme Knowledge Base** — Structured scheme data for efficient searching and matching.
* 🇮🇳 **Designed for India** — Focused on improving access to Indian government schemes and support programs.
* ⚡ **Fast & User-Friendly Interface** — Built with React and Vite.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Manan662007/AI-Driven-Scheme-Matching-for-Marginalized-Entrepreneurs.git
cd AI-Driven-Scheme-Matching-for-Marginalized-Entrepreneurs
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open the local URL shown in the terminal to access the application.
